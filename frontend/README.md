# UrbanNova — Jabalpur Civic Intelligence

Frontend demo for citizen complaints and municipal action.

## Implemented frontend features
- UrbanNova branding
- Citizen and municipal officer flows
- Live camera evidence capture UI
- Live GPS-only complaint location UI
- Aadhaar + mobile OTP demo verification
- 24-hour same-domain complaint guard using localStorage
- Officer sorting by newest / priority
- Resolution requires live after-work camera evidence
- Notices with officer add/edit/delete controls
- Citizen-visible future issue predictor
- Help Desk
- About / Jabalpur civic administration section

## Run
```bash
npm install
npm run dev
```

Real SMS OTP, secure Aadhaar handling, server-side duplicate enforcement, authenticated officer permissions, and production-grade predictive models require a backend.
